## Lacunas conhecidas desta versão
O fluxo foi feito antes de a equipe receber o slide das funcionalidades esperadas. Ainda faltam telas ou estados para:
- envio **em lote** com classificação por tema (esperada 1);
- **filtros por tema e por prazo** nos painéis (esperada 5; cobertura parcial);
- **avaliar a resposta**, útil ou não, com motivo (esperada 8);
- **análises anteriores semelhantes** (esperada 8, P1).

Também: o fluxo marca Mapa (T10) e Relatório (T11) como P1, mas os dois já foram implementados na PR #6.
